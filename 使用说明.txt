重走长征路 v0.6

1. 将本文件夹内所有文件上传到新 GitHub 仓库根目录（index.html 必须在根目录）。
2. Settings > Pages > Deploy from a branch > main > /(root) > Save。
3. 打开生成的 HTTPS 网站，向下滚动到“高德地图配置”，填写从高德开放平台申请的 Web端（JS API）Key。
4. 高德 JS API 2.0 要求安全验证。正式上线应按高德官方方案使用安全代理，切勿将安全密钥写在公开的 GitHub Pages 代码中。仅填 Key 可能因缺少安全验证而无法加载地图。
5. 在华为浏览器打开网站，添加到桌面。
6. 跑步数据保存在当前手机浏览器本地，不同域名之间不会自动迁移，请先从旧站导出 JSON，再在新站导入。

地图路线和历史地点坐标目前仍为示意，非考证的完整历史路线。
